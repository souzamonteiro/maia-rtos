## 1. Executive Summary (Observed Facts vs Assumptions)

### 1.1 Observed Facts
1. **Single-Translation-Unit Inclusion Model:** [`shell.cpp`](file:///Volumes/External_SSD/Documentos/Projects/maiaos/apps/shell/shell.cpp) is the top-level guest entry file (`916` lines) that directly `#include`s the generated parsers and 18 semantic/execution `.hpp` implementation headers into a single translation unit.
2. **Narrow Host Import Surface (13 functions):** All external OS/runtime interactions in `shell.cpp` go through **13 WebAssembly import declarations** (`MAIA_IMPORT`, lines `12–26`) grouped into three namespaces: `maia.stream` (3), `maia.vfs` (6), and `maia.process` (4).
3. **Cooperative Non-Blocking Step Machine:** The shell does **not** block on I/O inside parser or AST routines. Instead, `maiaos_step()` (`shell.cpp:840–916`) runs a bounded state machine (up to 16 steps per tick) that treats return value `-6` (`EAGAIN` / `WOULD_BLOCK`) from `maia_stream_*`, `maia_vfs_*`, and `maia_pipeline_wait` as a cooperative yield point.
4. **Static Global State (Non-Reentrant):** Every subsystem (`shell.cpp`, `shell-list.hpp`, `shell-glob.hpp`, `shell-word.hpp`, `shell-variables.hpp`, `shell-script.hpp`, `shell-expr.hpp`, `shell-test.hpp`, `shell-pattern.hpp`, `shell-return-status.hpp`, `shell-for.hpp`, `shell-conditional-loop.hpp`, `shell-loop-control.hpp`) stores its state in `static` file-scope globals. Only `initGlob()` (`shell-glob.hpp:52–67`) and `shellExprMatch()` (`shell-expr.hpp:199–210`) use heap allocation (`malloc`/`free`).
5. **Constrained Pipeline Execution:** In the current phase-one implementation (`shell-pipeline.hpp:18–33`), pipelines are restricted to `2..4` stages where non-final stages must be `cat` and the final stage must be `cat` or `wc` (`-l`, `-w`, `-c`). General arbitrary command pipelines require host-level `spawn` + `pipe_create` in `MaiaShellHost v1`.

### 1.2 Explicit Assumptions & Non-Assumptions
- **Do not assume reentrancy:** Two concurrent shell sessions cannot run in the same address space on SMP MaiaRTOS until the `static` globals listed in Section 4 are moved into a per-session `MaiaShellSession` struct (or serialized to a single shell task).
- **Do not edit generated files:** All files under `maiaos/apps/shell/generated/` and `maia-shell.cpp` are generated by MaiaCC and must be treated as read-only artifacts.
